# منصة يوم التبرع بالدم (Blood Donation Platform)

منصة ويب عربية بالكامل (RTL) لإدارة وتنظيم يوم موحّد للتبرع بالدم، ينظمه نادٍ طبي بشراكة مركز الدم الإقليمي.

## 1. الفكرة والأهداف

- **الزائر:** تصفح الحملة، والاطلاع على المواقع والترتيب وقائمة الأبطال، وتسجيل نية الحضور (شكلية)، وطلب فصيلة دم حرجة في حالات الطوارئ («أحتاج دمًا»).
- **مشرف الموقع:** تسجيل المتبرعين ميدانيًا يدويًا عبر واجهة ويب مخصصة وسريعة.
- **الأدمن:** إدارة الحملات، والمواقع، والمستخدمين، وإحصائيات الحملة وتجميدها.
- **الخصوصية والأمان:** الالتزام الصارم بخصوصية البيانات الصحية، وموافقات المتبرعين المستقلة، وتدوير وإخفاء البيانات الحساسة بعد انقضاء الفترة النظامية.
